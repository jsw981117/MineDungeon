# MineDungeon

지뢰찾기와 로그라이크 요소를 결합한 브라우저 게임

## 플레이하기

**🎮 [게임 플레이](https://jsw981117.github.io/MineDungeon/)**

## 게임 설명

지뢰찾기 방식으로 블록을 탐색하고, 적과 전투하며, 아이템을 수집하여 더 높은 층을 도달하는 것이 목표입니다.

### 주요 특징

- 9x9 고정 그리드
- 지뢰찾기 스타일 탐색
- 인벤토리 기반 장비 시스템
- 층별 난이도 증가

## 조작법

- **왼쪽 클릭**: 블록 탐색 / 적 공격 / 아이템 획득
- **우클릭 / 롱프레스**: 블록에 깃발 표시
- **인벤토리 클릭**: 아이템 장착/해제
